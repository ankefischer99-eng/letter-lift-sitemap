> Diese Datei steuert den JobAgent. Einfach hier auf GitHub bearbeiten
> (Stift-Symbol oben rechts) und speichern — die Änderungen gelten ab dem
> nächsten Lauf. **Remote + aus der EU arbeitbar ist fest eingebaut** und
> muss (und kann) hier nicht abgeschaltet werden.

## Einstellungen

```jobagent
keywords:
keywords_ausschluss:
sprachen: de, en
quellen: remotive, remoteok, jobicy, arbeitnow, wwr, arbeitsagentur
match_schwelle: nur-top
max_pro_tag: 0
arbeitszeit: egal
```

**Was die Felder bedeuten:**

| Feld | Bedeutung |
|---|---|
| `keywords` | Wonach gesucht wird, kommagetrennt (z. B. `grafikdesign, illustrator, ui design`). Leer = alles Remote-taugliche. |
| `keywords_ausschluss` | Stellen mit diesen Wörtern fliegen raus (z. B. `senior manager, sales`). |
| `sprachen` | In welchen Sprachen Stellen/Bewerbungen infrage kommen. |
| `quellen` | Aktive Job-Börsen. Einzelne entfernen = abschalten. |
| `match_schwelle` | `nur-top` (nur sehr gute Treffer), `gut` (auch solide Treffer), `alle` (alles anzeigen). |
| `max_pro_tag` | Obergrenze vorbereiteter Bewerbungen pro Tag, `0` = kein Limit. |
| `arbeitszeit` | `vollzeit`, `teilzeit` oder `egal`. |
